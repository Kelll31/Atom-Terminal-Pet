# AI Companion (M5Stack AtomS3R + FastAPI + MCP)

Этот проект представляет собой программно-аппаратный комплекс для голосового ИИ-компаньона, способного управлять вашим ПК (Windows).

## Структура проекта
- `backend/` - Серверная часть на Python (FastAPI, WebSockets, LangChain).
- `web/` - Web-панель управления (HTML, Bootstrap).
- `firmware/` - Прошивка для M5Stack AtomS3R / AtomS3 (PlatformIO).

## 1. Запуск Backend (Сервера)

Для автоматической установки всех зависимостей и запуска сервера просто кликните правой кнопкой мыши по файлу `start.ps1` в корневой папке и выберите **"Выполнить с помощью PowerShell"** (Run with PowerShell). 
Либо запустите его из терминала:
```powershell
.\start.ps1
```

Скрипт автоматически:
1. Проверит наличие Python.
2. Создаст виртуальное окружение.
3. Установит нужные библиотеки из `backend/requirements.txt`.
4. Запустит FastAPI сервер.

После запуска откройте веб-панель управления в браузере: [http://localhost:8000/](http://localhost:8000/).
В панели введите свои API-ключи (например, OpenAI) и настройте параметры.

## 2. Прошивка устройства (ESP32)

1. Откройте папку `firmware` в VS Code с установленным расширением **PlatformIO**.
2. В файле `firmware/src/main.cpp` укажите:
   - Ваш `ssid` (имя Wi-Fi сети).
   - Ваш `password` (пароль от Wi-Fi).
   - `websocket_server` (IP адрес вашего компьютера в локальной сети, на котором запущен backend).
3. Подключите M5Stack AtomS3R по USB и нажмите **Upload** (Загрузить) в PlatformIO.

## Использование

1. Убедитесь, что сервер запущен.
2. Включите M5Stack. На экране должен появиться зеленый цвет, если он успешно подключился к Wi-Fi и WebSocket.
3. Нажмите и удерживайте **кнопку** (под экраном). Экран загорится желтым — говорите команду.
4. Отпустите кнопку. Устройство отправит аудио на сервер, обработает и пришлет ответ, который будет воспроизведен через динамик.

## Доступные инструменты (MCP Tools)
- Управление громкостью (`set_volume`)
- Нажатие сочетаний клавиш (`press_keys`)
- Запуск простых приложений (`open_program`)

Включать/выключать их можно через Web UI панель управления.
